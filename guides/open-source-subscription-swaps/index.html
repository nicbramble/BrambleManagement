8 subscriptions you can replace with open-source tools

Wispr Flow to FreeFlow, Photoshop to GIMP, and six more practical swaps—with GitHub links, setup steps, and the costs to check before cancelling.

You probably do not need another monthly app bill. You need the job it does: dictate a message, edit a thumbnail, record a tutorial, or move data between apps.

These eight projects on GitHub can replace common paid workflows. Start with one you actually use. Free software does not always mean a free setup: AI usage, storage, hosting, and your time can still cost money. Some projects offer a free open-source core alongside paid features.

Quick picks: FreeFlow for Mac dictation, GIMP for image editing, OBS for recording, and Joplin for personal notes. Activepieces and Nextcloud take more setup. The numbered GitHub links at the end match the eight swaps below.

1. Wispr Flow → FreeFlow

For: Mac users who want to talk instead of type. The paid app’s name is Wispr Flow, sometimes written as “WhisperFlow.”

FreeFlow turns speech into text in your current app, cleans up the transcript, and can edit selected text from a spoken instruction. It is a free Mac app with MIT-licensed source code.

Get started

  1. Open the FreeFlow GitHub link below and download the app using its README’s download link.
  2. Install it and grant the requested Mac permissions.
  3. Create a Groq API key and enter it in the app’s settings.
  4. Hold Fn, speak a short message, and release to paste the result. Add names or jargon to the custom vocabulary.

The catch: The default setup sends audio and cleanup requests to your configured AI provider. Groq has a free tier with limits; other providers can charge for usage. Local providers are supported but require a compatible transcription backend as well as a cleanup model, and can be slower. This is a Mac replacement, not a replacement for every Wispr Flow platform.

Try before switching: Dictate the same paragraph in both apps and compare punctuation, names, and speed.

2. Photoshop → GIMP

For: Creators making thumbnails, editing photos, or working with layered images.

GIMP is a free image editor with layers, selections, masks, retouching tools, and plugins. Its GitHub repository mirrors the project’s source; the official GIMP website provides ready-to-install releases.

Get started

  1. Follow the download link in the repository README to GIMP’s official website. Choose a stable release for your computer.
  2. Open a copy of an image and try a crop, color adjustment, and text layer.
  3. Save the editable project as XCF and export a JPG or PNG for posting.

The catch: The interface and shortcuts differ from Photoshop. Photoshop-specific plugins, AI features, and complex PSD files may not transfer cleanly. Keep original files and test a representative project first.

Try before switching: Recreate one real thumbnail, including the layers you normally edit later.

3. Loom → OBS Studio

For: People paying mainly to record screen walkthroughs, lessons, or demos.

OBS is free, open-source software for screen recording and streaming. You can combine a screen, webcam, and microphone in one recording on Windows, macOS, or Linux.

Get started

  1. Download OBS through the official website linked in its repository.
  2. Run the Auto-Configuration Wizard for recording.
  3. Add a screen-capture source and, if needed, a webcam source. Check your microphone in the audio mixer.
  4. Record a one-minute test, play it back, then share the file through storage you already use.

The catch: OBS replaces the recording part of Loom. It does not provide Loom’s hosted video library, instant sharing pages, viewer comments, or AI summaries. Large recordings also need storage and upload time.

Try before switching: Record and deliver a tutorial to someone using your existing file-sharing setup.

4. Evernote → Joplin

For: Personal notes, research, checklists, and saved web pages.

Joplin is a free, open-source notes app for desktop and mobile. Notes remain available offline. It supports notebooks, search, attachments, a browser web clipper, and imports from Evernote’s ENEX exports.

Get started

  1. Install Joplin using the official links in its repository.
  2. Export one Evernote notebook as ENEX and import it into Joplin on desktop.
  3. Check formatting, attachments, tags, and a few searches.
  4. If you need multiple devices, choose a supported sync destination and test a note in both directions.

The catch: Joplin Cloud is an optional paid service. Using another sync destination can avoid that subscription, but its storage limits or costs still apply. Shared team workflows may differ from Evernote. Export and check your notes before cancelling.

Try before switching: Use one imported notebook for a week and confirm you can find its attachments on your phone.

5. Adobe Acrobat / Smallpdf → Stirling PDF

For: Everyday PDF jobs such as merging, splitting, compressing, converting, and OCR.

Stirling PDF brings many PDF tools into one interface. You can run it on your own machine or server rather than relying on a paid online PDF service for routine processing.

Get started

  1. Open the repository and follow its installation documentation for a local setup or self-hosted server.
  2. Start with a copy of a non-sensitive PDF.
  3. Merge two files, extract pages, and compress the result. Open the output to check readability.

The catch: Stirling PDF is open-core: parts of the project use separate licenses, and some capabilities require paid plans. Check the edition and features you need. It is not a promise of complete Acrobat editing compatibility. Self-hosting adds maintenance and potential server costs; the data path depends on the deployment you choose.

Try before switching: Run your three most common PDF tasks and inspect every output.

6. Zapier → Activepieces Community Edition

For: Automating repetitive handoffs between apps.

Activepieces has a visual builder for triggers and actions. Its Community Edition is MIT-licensed and can be self-hosted. A useful first workflow: when a form submission arrives, add a row to a spreadsheet.

Get started

  1. Use the repository’s deployment documentation to install Community Edition on a machine or server you control.
  2. Check that your exact apps and actions have supported integrations, called pieces.
  3. Connect a test form and spreadsheet, build one flow, and send sample submissions.
  4. Check the run history and confirm each submission creates one correct row before moving a live workflow.

The catch: Enterprise features use a commercial license. Hosting, connected services, and AI APIs can still cost money. Integration coverage may differ from Zapier, and you maintain the self-hosted service. Test failures and retries as well as the happy path.

Try before switching: Move one low-risk workflow and compare its results for a week.

7. Dropbox → Nextcloud

For: People who want file sync and sharing on storage they control.

Nextcloud is an open-source server for storing, syncing, and sharing files. Desktop and mobile clients connect to your instance. It makes the most sense if you already have suitable hardware or want to manage your own storage.

Get started

  1. Follow the repository’s official server-installation links. Decide where it will run and where backups will live.
  2. Create your account and connect a desktop or mobile client.
  3. Sync a small test folder and try a share link.
  4. Test restoring a file from a separate backup before moving important data.

The catch: Free server software does not give you free disks, unlimited storage, backups, or hosting. Updates and availability become your responsibility, unless you pay a provider to manage them. Sync alone is not a backup.

Try before switching: Confirm your test folder syncs across devices and that a deleted file can be recovered.

8. TeamViewer → RustDesk

For: Basic remote access to your own computers or helping someone with their permission.

RustDesk is an open-source remote desktop app. You can use its public connection infrastructure or run the open-source ID and relay server yourself for more control.

Get started

  1. Install a stable RustDesk release on both computers from the repository’s download link.
  2. Start a session with the remote computer’s ID and the owner’s approval.
  3. Test screen control and file transfer for the work you actually do.
  4. If you need your own infrastructure, follow the separate Server OSS instructions and configure both clients to use it.

The catch: RustDesk Server Pro adds paid administration features. Running your own server adds setup and hosting costs. A basic remote session is not the same as replacing a company’s full device-management system.

Try before switching: Complete a real support session across two different networks.

Pick the subscription worth replacing

Start with a job you do often and can test easily. FreeFlow, GIMP, OBS, or Joplin are good first trials. Take more time with a server you need to keep running, such as Activepieces or Nextcloud.

  1. Write down the features you actually use in the paid app.
  2. Try the replacement on one real task and keep your original files.
  3. Check export, sharing, sync, or recovery—whichever your workflow depends on.
  4. Compare the bill you can remove with new API, storage, hosting, and maintenance costs.
  5. Cancel only after the replacement does the job reliably and your data is accessible.

Your potential annual savings: 12 × the monthly subscriptions you actually cancel, minus annual replacement costs. For annual plans, use the actual renewal amount. Do not count all eight as savings unless you currently pay for all eight.
