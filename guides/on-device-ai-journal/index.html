On-device AI Journal

Download the shortcut and create your journal folder in Files.

Download AI Journal ↗
View resource artwork

1. Download the shortcut

Tap Download AI Journal above on your iPhone, then add it to Shortcuts.

2. Create your journal folder

  1. Open Files and tap Browse → iCloud Drive → Shortcuts.
  2. Tap More (•••) → New Folder.
  3. Name it journal.

If Shortcuts asks you to choose a save folder, select journal. You can also select it in the shortcut’s Save File action.
