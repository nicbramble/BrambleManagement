What would ChatGPT look like? Try this selfie prompt

Ask ChatGPT to imagine itself in a messy, accidental iPhone selfie. Copy the prompt and try it in your chat.

1. Open ChatGPT

Use an existing conversation if you want to keep the context of your chats. You’ll need image generation available on your account.

2. Copy and send this prompt

Copy, customize, practice
ChatGPT, you've been with me for a while now and I want to see what you look like. Please generate a photo of yourself that looks like a simple iPhone snapshot: no prominent subject, no intentional composition; completely ordinary, even a bit failed, like a momentary snap. In the photo, include slight motion blur, unbalanced lighting, mild overexposure, a weird angle, and a messy frame. Overall, make it look like it was accidentally taken while pulling the phone out of your pocket, conveying an excessively real and casual selfie vibe.

ChatGPT has no physical appearance. This asks it to imagine a fictional version of itself.

3. Check the result

Look for a tilted angle, messy crop, slight blur and uneven lighting. The picture should feel like an accidental phone snap.

If it looks too polished, send:

Copy, customize, practice
Make this image feel more accidental: tilt the frame, crop part of the face, add slight motion blur and uneven lighting, and mildly overexpose one area. Keep the same imagined person and setting.

If ChatGPT only replies with text, ask: Generate the image now, using an imagined human version of yourself.
